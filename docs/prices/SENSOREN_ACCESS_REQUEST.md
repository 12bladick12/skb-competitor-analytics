# Запрос доступа к каталогу Sensoren

Тема: получение каталога, цен и характеристик для мониторинга

Здравствуйте!

Нам требуется получать актуальный ассортимент производителей Autonics, Balluff, Pepperl+Fuchs, IFM Electronic, LANBAO и SICK для анализа цен.

Нужные данные: производитель, артикул, наименование, URL карточки, опубликованная цена и валюта, наличие/срок поставки, технические характеристики, дата актуальности. Отдельно важно различать отсутствие открытой цены и цену по запросу.

Подскажите, пожалуйста:

1. Доступны ли партнёрский API, YML/XML/CSV-фид или регулярный XLSX-прайс с характеристиками? Как получить доступ, документацию и сведения о частоте обновления?
2. Если выгрузки нет, можно ли согласовать сбор общедоступных страниц этих производителей с фиксированного адреса? Наш клиент представляется `PriceMonitor/1.0`, выполняет последовательные запросы с паузой и соблюдает robots.txt. Готовы настроить рекомендованный вами лимит и время работы.
3. Какой способ получения полного списка товаров и последующих изменений вы рекомендуете?

Сейчас обычный клиент получает HTTP 503 с JavaScript-проверкой RCPC, хотя страницы доступны в интерактивном браузере. После обнаружения проверки автоматический сбор прекращён. Просим предоставить согласованный способ доступа.

Контактное лицо и адрес сборщика сообщим при согласовании.
