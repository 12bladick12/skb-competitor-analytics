# Sensoren: подключение браузерной сессии

Обновление 29.09.2026. Внешний агент использует `SensorenBrowserClient` по умолчанию — и для заданий из Excel/CSV, и для обхода каталога выбранных производителей. Облачные сборщики остальных сайтов не меняются.

## Работа транспорта

- Одна анонимная сессия Chromium переиспользуется внутри запуска. HTML и XML получает HTTP-клиент этой сессии. Cookies не сохраняются на диск и не выводятся в журнал.
- При известном ответе RCPC браузер исполняет JavaScript. Разрешены максимум два открытия исходного URL; переходы, запрещённые robots.txt, блокируются.
- После восстановления повторяется HTTP-запрос. Оставшаяся проверка прекращает сбор. Лимит — три восстановления за десять минут.
- Между запросами выдерживается минимум три секунды либо больший Crawl-delay. Перенаправления проверяются вручную; robots.txt обновляется каждые 30 минут.
- Авторизация, HTTP 403/429, CAPTCHA и неизвестные проверки не запускают восстановление. Retry-After останавливает источник с объяснением.
- Сохраняются прежние проверки производителя, артикула и характеристик. При отмене или потере права на очередь результат не записывается как успешный. Сетевой запрос ограничен 20 секундами; отмена учитывается после его завершения/тайм-аута.
- При перезапуске процесса создаётся новая сессия, а задания восстанавливаются из общей очереди. Снимок, уже полученный перед сбоем БД, сохраняет первоначальное время получения.

## Запуск внешнего агента

На компьютере сборщика один раз установить зависимости проекта и Chromium:

```powershell
python -m pip install -r requirements.txt
python -m playwright install chromium
```

Параметры Supabase остаются в локальном `.streamlit/secrets.toml`, раздел `[database]`. Их нельзя загружать в GitHub. Затем использовать `start_sensoren_agent.cmd` либо:

```powershell
python -m price_monitor.sensoren_agent --enable --fresh-connections --transport browser
```

Если секреты хранятся в другом месте, передать `--secrets "путь\secrets.toml"`. В журнале должен появиться транспорт `SensorenBrowserClient`. Текущий процесс должен оставаться работающим, чтобы кнопки Streamlit могли передавать ему задания. Новый транспорт не требует переносить Supabase или устанавливать Chromium в Streamlit Community Cloud.

Для возврата к прежнему клиенту есть `--transport http`; этот режим сам по себе не устраняет RCPC/503. Одновременно работает только один внешний агент: право на очередь защищено арендой с heartbeat.

## Проверки

```powershell
python -m unittest discover -s tests_prices -v
python tools/check_sensoren_transport.py --discovery
```

Вторая команда выполняет ограниченную живую проверку: шесть примеров, затем по одной странице бренда, категории, дополнительной карточке и странице пагинации. Рабочая БД не меняется; локальный отчёт сохраняется в `data/sensoren_browser_integration/check.json`.

На 29.09.2026 пройдены 26 автоматических тестов, включая RCPC, истечение сессии (моделирование), остановку при отказах, запрет перенаправлений, сохранение характеристик и исключение чужого производителя при обходе каталога. Живая проверка получила 30 страниц с HTTP 200: 12 карточек с характеристиками и 18 страниц навигации шести брендов. Использованы один браузерный контекст и одно восстановление сессии. Это выборочная проверка; полнота большого каталога и многочасовая устойчивость ещё не установлены.

Машиночитаемый протокол: [30 проверенных страниц](sensoren_browser_check_2026_09_29.json).

## Рабочая очередь и реальная выгрузка

Новый агент подключён 29.09.2026. Прежний простаивающий процесс остановлен; старая очередь и история сохранены. Обе локальные копии агента обновлены, чтобы запуск старого ярлыка также использовал новый транспорт.

- **Запуск №7:** создан в общей очереди приложения, шесть производителей, завершён успешно с 06:55:20 до 06:56:05 UTC (45 секунд). Все шесть наблюдений — HTTP 200 и опубликованная цена. В Supabase сохранены 114 характеристик (23, 13, 17, 13, 25, 23 по порядку примеров).
- **Запуск №8:** настоящий обход каталога с выбором только ifm. Сохранены восемь карточек с ценами и характеристиками, других производителей нет. Затем выполнена плановая остановка для проверки отмены. После неё число сохранённых карточек осталось восемь, страниц в состоянии pending/processing — ноль. Статус «Остановлен» здесь ожидаем; это не отказ сайта. Запуск №6 не возобновлялся.
- **Проверка в браузере Streamlit:** из раздела «Запуски» выбран №7, скачаны `run_7_page_1.xlsx` и `run_7_page_1.csv`. Файлы повторно открыты и сверены. XLSX: листы «Результаты» (6 моделей) и «Характеристики» (114 строк). CSV: 6 строк, 57 отдельных столбцов характеристик. Проверка ожидала именно кнопки выбранного запуска после завершения перерисовки.
- Внешний агент после проверок остаётся подключённым и ожидает пользовательские задания.

[Протокол рабочей очереди, остановки и скачивания файлов](sensoren_browser_queue_2026_09_29.json).

Локальная попытка выгрузить все документы одним PostgreSQL-ответом зависла на чтении; диагностические процессы завершены, данные не изменялись. Проверка реального XLSX/CSV выполнена через облачное приложение и прошла. Причина локальной сетевой задержки отдельно не установлена; это не объявляется исправлением сетевого канала Supabase.

Полный многочасовой сбор всех каталогов в этой проверке не запускался. Истечение сессии проверено моделированием RCPC; реальный срок её действия пока не измерен. Обоснование выбора библиотеки: [исследование вариантов](SENSOREN_OPTIONS_2026_09_29.md).
