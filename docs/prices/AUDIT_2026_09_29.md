# Аудит Sensoren, ТЕКО и выгрузки характеристик

Дата: 29.09.2026. Проверены текущие HTTP-ответы, правила robots.txt, сохранённые полные карточки предыдущего дня, исходный код сборщиков и схема хранения/выгрузки. Проверка выборочная по карточкам: полнота всех характеристик во всех категориях ещё не подтверждена.

## 1. Sensoren: причина отказа и допустимые способы доступа

С локального компьютера сборщика `https://sensoren.ru/robots.txt` отвечает HTTP 200. Каталог, проблемная карточка LANBAO и шесть примерных карточек выбранных производителей возвращают HTTP 503. Ответы имеют размер 171–225 байт, сервер nginx; `Retry-After` отсутствует. Тело содержит JavaScript, устанавливающий cookie `RCPC` и перенаправляющий браузер на `?attempt=1`. Значения cookie в этот отчёт не включены.

Это подтверждает проверку браузера на стороне сайта. Код 503 в данном случае не доказывает перегрузку сервера или неисправность Supabase. Сохранённые ответы 28.09 содержат полноценный HTML с ценами и характеристиками: постоянная потребность в JavaScript для самих товарных данных не установлена. Новые защищённые ответы не содержат товарных данных.

| Способ | Что проверено | Решение |
|---|---|---|
| Обычный HTTP, постоянная сессия | Текущий ответ — RCPC/503, ранее был 200 | Остановить источник при проверке, не выдавать ответ за карточку |
| Каталог по выбранным брендам | Страницы брендов содержат популярные товары и ссылки в категории | Использовать категории бренда, страницы каталога и сверку производителя |
| XML-карты сайта | Адрес опубликован в robots.txt; сохранённые карты использовались очередью | Дополнительный способ найти URL, не источник цены; текущая доступность всех карт не подтверждена |
| Поиск/AJAX/Bitrix | Общие правила закрывают `/quick_search/`, `/bitrix/`, большинство параметров и фильтры | Не использовать запрещённые маршруты |
| Браузерная автоматизация | Наличие RCPC подтверждено, автоматическое прохождение проверки не согласовано | Не считать браузер способом гарантированно разрешить сбор; согласовать доступ |
| API/фид/прайс поставщика | Публичная документация/ценовой фид в проверенных страницах не найдены | Запросить у Sensoren; отсутствие результата поиска не доказывает отсутствия партнёрского API |
| Согласованный доступ для адреса сборщика | Разрешение и лимиты пока не получены | После согласования проверить HTTP, затем небольшой запуск по каждому бренду |

Готов [запрос поставщику](SENSOREN_ACCESS_REQUEST.md). Он не отправлялся. Подмена робота поисковой системы, самостоятельная генерация проверочных cookie, ротация адресов и обход CAPTCHA не входят в выбранный режим работы.

### Маршруты выбранных производителей

| Производитель | Начальная страница |
|---|---|
| Autonics | https://sensoren.ru/brands/autonics/ |
| Balluff | https://sensoren.ru/brands/balluff/ |
| Pepperl+Fuchs | https://sensoren.ru/brands/pepperl_fuchs/ |
| ifm | https://sensoren.ru/brands/ifm_electronic/ |
| LANBAO | https://sensoren.ru/brands/lanbao/ |
| SICK | https://sensoren.ru/brands/sick/ |

На страницах брендов показан «Топ 10», поэтому остановка на этих страницах даёт неполный ассортимент. Пример ссылки на полный раздел: [индуктивные датчики LANBAO](https://sensoren.ru/catalog/beskontaktnye-datchiki-polozheniya-obekta/induktivnye_datchiki/brand_lanbao/). Обход следует опубликованным ссылкам `brand_<производитель>`, параметрам `PAGEN_N` и XML-картам. Глобальное меню всех производителей не разворачивается повторно на каждой странице. Известные чужие бренды исключаются из очереди; окончательное решение принимается по основной карточке. Цены берутся из основной области предложения, характеристики — из `.characteristics-all li`.

Актуальный robots.txt для `User-agent: *` допускает проверенные страницы брендов и `brand_lanbao`, а также `?PAGEN_1=2`; запрещает `/quick_search/?q=…` и `?attempt=1`. Каждый фактический запрос повторно проходит политику клиента. Адрес карты сайта: https://sensoren.ru/sitemap.xml.

Индексированные публичные страницы использовались для проверки структуры навигации. Они не загружаются в историю как свежие цены. Полный проход каталога после изменения навигации пока не проверен из-за текущего ограничения сайта.

## 2. ТЕКО: только собственная продукция

Сайт https://teko-com.ru/catalog/ — смешанный каталог. Ошибка прежней версии: производитель всех карточек этого домена автоматически становился «ТЕКО». В сохранённых характеристиках у ряда таких записей уже было указано «Бренд: Autonics».

Теперь основание для включения — явное поле «Бренд»/«Производитель» основной карточки, соответствующее ТЕКО. Упоминание ТЕКО в меню, подвале или домене не подтверждает производителя. Карточка иного бренда пропускается в полном обходе; в задании по явной ссылке возвращается несовпадение производителя без цены. Если бренд не подтверждён, товар не включается в базу ТЕКО.

Проверено текущими HTTP 200:

- [ТЕКО CP S254R-3 (PG9)](https://teko-com.ru/catalog/product/cp-s254r-3-pg9/): бренд ТЕКО, 18 характеристик; принимается.
- [Autonics BTF30-DDTL](https://teko-com.ru/catalog/product/btf30-ddtl/): бренд Autonics, 15 характеристик; исключается.

Производитель может быть неизвестен до чтения карточки, поэтому часть страниц других брендов всё ещё потребуется открыть для проверки. Запрещённые robots.txt маршруты `/filter/`, параметры `arrFilter` и AJAX для ускорения не используются.

Ранее сохранённые записи проверяются по имеющимся характеристикам. Таблица `product_scope` содержит подтверждённого производителя, состояние и хеш проверенного документа. Чужие и неподтверждённые товары исключаются из базы, сравнения и выгрузок товарных результатов. Диагностические ошибки заданий остаются в журнале. Исходные наблюдения и история не удаляются. При изменении документа прежнее подтверждение перестаёт действовать до новой проверки.

## 3. Характеристики и выгрузка

Характеристики уже сохранялись в `product_documents`. Наблюдения содержали ссылку `{"ref":"…"}`, но выгрузка результатов не раскрывала её. Другая ошибка: перечень столбцов брался только из первой строки, поэтому характеристики последующих строк терялись.

Исправлено:

- массовое раскрытие документов по ссылкам наблюдений;
- отдельные столбцы `Характеристика: …` в CSV и XLSX;
- дополнительный лист XLSX «Характеристики»: источник, производитель, артикул, модель, запуск, время, ссылка, группа, параметр, значение;
- описание, ссылки на документы и число характеристик;
- объединение столбцов всех строк, включая редкие параметры;
- экранирование значений, похожих на Excel-формулы;
- сохранение исторического снимка: если в старом ответе характеристик не было, более поздние данные не подставляются на старую дату.

Экспорт из «Запусков» выгружает текущую страницу, как указано в интерфейсе. Весь выбранный набор доступен через «Базу товаров». Отсутствующие характеристики явно обозначаются; нулевая цена для ошибок не создаётся.

Парсеры дополнены обработкой вложенных подписей Sensoren и структурированных свойств `additionalProperty` внутри товара. Специальные селекторы сайтов сохраняются; характеристики исполнений BESKONTA записываются отдельно для каждого артикула.

## 4. Проверки и границы результата

Локальные автоматические проверки: производитель ТЕКО; пропуск чужого бренда в каталоге и явном задании; ограничение выбранных брендов Sensoren; обнаружение RCPC и прекращение запросов; вложенные подписи характеристик; CSV/XLSX и дополнительный лист; восстановление документов и сохранение исторических снимков; недействительность подтверждения после изменения документа.
