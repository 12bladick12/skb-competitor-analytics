# Постоянная база и обновление товаров

Товары, история цен и выбранные соответствия хранятся постоянно. Повторный сбор не создаёт новый замер из сохранённой месячной цены.

| Действие | Периодичность |
|---|---|
| Поиск ссылок на новые карточки | Каждый запуск |
| Полная обработка новой карточки | Сразу после обнаружения |
| Цены, характеристики и исполнения известных карточек | Один раз в календарный месяц UTC |
| Проверка отсутствующих карточек | После полного успешного обхода выбранного каталога |

Новое исполнение внутри старой карточки обнаруживается при месячном обновлении. Сохраняются даты фактической проверки цены и карточки.

Сбой сети, 403/429, пустой результат парсера и незавершённый обход не означают удаление. Для архивирования нужны две проверки 404/410 с интервалом не менее суток. Доступная карточка остаётся активной, даже если её ссылка исчезла из перечня.

Отсутствующее исполнение проверяется по полному составу вариантов карточки. Подтверждённый переезд на новый URL сохраняет идентификатор и историю. При архивировании сохраняются цены и сравнения.

Подбор использует характеристики карточек, проверенные правила обозначений и ранее подтверждённые сведения. Недостающие значения не заполняются предположениями.
