# Аудит источников — 28 сентября 2026

**Дополнение после облачного запуска:** Sensoren вернул HTTP 403 из Community Cloud. Повторная проверка с компьютера владельца получила цены всех шести брендов с HTTP 200. Добавлен отдельный локальный сбор с сохранением в Supabase. [Диагностика и порядок работы](SENSOREN.md).

Проверены пять доменов: `sensoren.ru`, `beskonta.ru`, `mega-k.com`, `teko-com.ru`, `sensor-com.ru`. СЕНСОР подтверждён ссылками из `sensor_com_processed.rar` и сайтом производителя. Для Sensoren отдельно проверены карточки всех шести согласованных иностранных брендов.

Это технический аудит ограниченной выборки: 31 проверка URL robots.txt, карт сайта, каталогов, реальных и несуществующих карточек, затем сквозной запуск готового сборщика. Получены реальные HTTP-ответы из этой среды. Доступность всего ассортимента и допустимая максимальная нагрузка не измерялись. Выявленные ограничения применяются в сборщике; обещания отсутствия будущих блокировок нет.

## Карточки аудита

### Sensoren

[Каталог](https://sensoren.ru/catalog/), [robots.txt](https://sensoren.ru/robots.txt), [sitemap.xml](https://sensoren.ru/sitemap.xml).

Sitemap — индекс файлов, в том числе `sitemap-iblock-2.xml` и частей каталога. Для будущего наполнения списка URL можно читать разрешённые карты и страницы категорий; v1 работает с загруженными ссылками. Общая группа `User-agent: *` запрещает URL с query string, кроме отдельных Allow, включая PAGEN. Форму поиска видно в HTML (`/catalog/`, параметр `q`); запросы поиска не выполнялись из-за robots.txt. Формы обратной связи содержат CAPTCHA, но она не препятствовала чтению проверенных карточек. Публичный документированный API или фид цен не подтверждён.

Проверенные модели: [SI5000](https://sensoren.ru/product/datchik_potoka_ifm_electronic_si5000/), [THD-R-T](https://sensoren.ru/product/datchik_temperatury_autonics_thd_r_t/), [BSP B600-EV003-A02A0B-S4](https://sensoren.ru/product/datchik_davleniya_balluff_bsp_b600_ev003_a02a0b_s4/), [RaDec-D](https://sensoren.ru/product/datchik_dvizheniya_pepperl_fuchs_radar_sensor_radec_d/), [DPG-10TN](https://sensoren.ru/product/datchik_davleniya_lanbao_dpg_10tn/), [FTS-I100F14A](https://sensoren.ru/product/datchik_potoka_sick_fts_i100f14a/). Несуществующий URL вернул HTTP 404. Стабильность: средняя, селекторы зависят от оформления сайта; наличие нельзя выводить из кнопки покупки или срока поставки.

### BESKONTA

[Каталог](https://beskonta.ru/catalog/all/), [robots.txt](https://beskonta.ru/robots.txt), [карта сайта](https://beskonta.ru/sitemap-1.xml), [BORE01](https://beskonta.ru/product/bore01-opticheskiy-fotobarer/).

Sitemap содержит URL категорий и товаров. Каталог показывает варианты сортировки и 15/30/45 товаров на страницу. robots.txt ограничивает поиск `/search/`, `?query=`, сортировку, `pageSize` и некоторые комбинации пагинации. Эти интерфейсы не используются. В HTML выбранной карточки маркировка `BORE01-S2000-8-20-P01`, цена 28 960 RUB. Обобщённая модель `BORE01` недостаточна для цены конкретного исполнения. Несуществующий товар вернул 404. Стабильность: средняя для отдельных исполнений, требуется внимание к конфигуратору; эмуляция выбора вариантов и закрытые API не реализованы.

### МЕГА-К

[Каталог](https://mega-k.com/catalog), [robots.txt](https://mega-k.com/robots.txt), [карта сайта](https://mega-k.com/sitemap.xml), [PS2-36M70-12B11-K](https://mega-k.com/products/ps2-36m70-12b11-k).

Sitemap содержит HTTP-ссылки; для проверенной карточки доступен HTTPS. Цена находится в `.details-payment-price .price-current` и вложенном Offer. `sku` в Offer — числовой идентификатор, отличающийся от модели в заголовке: сохраняется введённая модель, а не подмена её этим кодом. `availability` у проверенного товара — InStock. Поиск `/search`, аккаунт, корзина и фильтры ограничены robots.txt. Несуществующий товар вернул 404. Стабильность: относительно высокая в проверенной структуре благодаря HTML и микроданным; устойчивость всего каталога не подтверждена.

## Ограничения и воспроизводимость

При аудите не обнаружена CAPTCHA, блокирующая чтение выбранных карточек; это наблюдение по выборке. Разрешённая максимальная частота запросов не опубликована в проверенных robots.txt и не устанавливалась нагрузочным тестом. В v1 выбрано не более одного запроса на сайт одновременно и минимум две секунды между запросами; Crawl-delay увеличивает интервал. У разных сайтов сбор идёт параллельно.

Один адаптер приходится на сайт; у Sensoren он обслуживает шесть производителей. Браузерная автоматизация не требуется для подтверждённых страниц. При новых динамических карточках приложение показывает отсутствие цены, несовпадение исполнения или ошибку структуры; оно не придумывает цену и не использует соседние предложения. Цена по запросу автоматически не запрашивается у менеджеров.

Фактические HTTP-ответы и метаданные: `docs/audit/http_audit.json`, `http_audit_extra.json`, `http_audit_cases.json`; сквозная проверка — `live_collection.json`. Исходные полные ответы доступны локально в `docs/audit/raw`, копии важных фрагментов и robots.txt входят в `tests/fixtures`. Полные HTML исключены из Git и образа. Реальный случай без цены проверен у СЕНСОР; сценарии «нет цены» и «по запросу» остальных источников проверяются на контролируемых модификациях сохранённых карточек. Их нельзя считать доказательством наличия именно таких товаров в текущем каталоге.

Дата, URL, HTTP-код, время ответа, размер и SHA-256 сохранены для каждого аудированного ответа. HTTP-проверки не выполняют JavaScript; вывод о достаточности HTML основан на наличии самих цен в ответах. Приложение не сопоставляет предложения с вашей номенклатурой и не оценивает юридический статус источников.
