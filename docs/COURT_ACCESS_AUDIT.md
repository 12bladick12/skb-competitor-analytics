# Проверка доступа 16 октября 2026

Цель: отличить ошибки ожидания браузера от ограничения доступа и найти рабочие
публичные маршруты без новых зависимостей. Рабочая база и облачное приложение не менялись.

## Дополнительные проверки и исправления

Последующая проверка нашла исправимые ошибки, поэтому первоначальный неуспех
браузеров не доказывает невозможность доступа ко всем источникам.

- Уведомление КАД/Банка решений закрывалось обработчиком, после чего повторный
  клик ждал уже скрытую кнопку. Повторный клик удалён и проверен браузерным тестом.
- После ввода ИНН переход Tab в Банке решений открывал список судов поверх кнопки
  поиска. Обычный клик по подписи поля сохраняет введённый запрос и закрывает список.
- Верховный суд рендерит форму до подключения React. Ранний ввод терялся при
  инициализации. Ожидание обработчиков вернуло рабочий поиск по всем пяти компаниям
  локально; исправленный поиск также дал ответ из GitHub Actions.
- СудАкт больше не застревает на противоречивой выдаче: продолжает поиск по другим
  названиям, сохраняя пропуск, его страницу и доказательство. Новый проход повторяет
  запросы; пропуск не превращается в подтверждённый нулевой результат.
- Браузер работает в отдельном процессе с внешним лимитом 90 секунд на страницу.
  Зависание протокола или закрытия страницы останавливает только этот процесс;
  позиция сохраняется, другие источники продолжают работу. На Linux наблюдавшиеся
  зависания ВС/КС завершились за 90,0–90,1 секунды. Прерывание, аварийное завершение
  и последующая успешная проверка другого источника покрыты тестами.

### Дополнительный рабочий маршрут Верховного суда

Реализован `vsrf_http`: обычная публичная страница `/lk/practice/claims` с теми же
параметрами, которые отправляет браузерная форма. Ответ содержит опубликованные
карточки и метаданные пагинации; платный API и авторизация не используются.
Адаптер обходит ИНН и все названия реестра, сохраняет позиции страниц, проверяет
повторы и число уникальных карточек. Снимок поисковой страницы сохраняется как
доказательство; тексты судебных актов этим маршрутом не загружаются.

Локальная проверка:

- «НПК ТЕКО»: одна запись `309-ЭС23-20007 (1)`, поступление 29.08.2023,
  исходное дело `А76-38023/2021`. АО НПК «ТЕКО» опубликовано среди третьих лиц.
  ИНН в этой карточке отсутствует, поэтому запись остаётся кандидатом.
  Дополнительно открылась [копия определения ВС от 19.10.2023](https://legalacts.ru/sud/opredelenie-verkhovnogo-suda-rf-ot-19102023-n-309-es23-20007-po-delu-n-a76-380232021/):
  HTTP 200, точного ИНН также нет. Официальная ссылка КАД по номеру дела
  `/Kad/Card?number=А76-38023/2021` вернула HTTP 200 с `pravocaptcha` вместо карточки.
- «ЗАО СЕНСОР»: 26 карточек получены на двух страницах — 20 + 6. Принадлежность
  каждой записи конкретному юрлицу не подтверждена. Число результатов поиска
  нельзя показывать как число судебных дел отслеживаемого конкурента.
- По проверенным названиям МЕГА-К, СОЧЕР и Сенсорен Электро браузерная выдача
  показала ноль. Это не доказательство отсутствия дел по другим вариантам названия
  или в других судах. При первой HTTP-проверке ИНН МЕГА-К был единичный `SSLError`;
  повторный обход ИНН и обоих названий МЕГА-К завершился ответами 200 и нулевыми
  результатами этих запросов. Полная устойчивость не установлена.

Каждая карточка хранит опубликованные поля, текст, ссылки и доказательство.
Совпадение названия не создаёт подтверждённого дела или новости. Статус адаптера
остаётся `partial`, даже если все страницы конкретного поискового запроса пройдены.

[Облачная проверка 0517c20](https://github.com/12bladick12/skb-competitor-analytics/actions/runs/38876123855)
завершилась как диагностическое задание. ФНС снова подтвердила пять исходных
организаций. Браузерный ВС работал с окном и без него. HTTP-поиск ВС дал ответы
для части запросов, но получил `ConnectTimeout` для названия ТЕКО, ИНН СЕНСОР и
названия Сенсорен Электро. Это препятствует заявлению об устойчивой полной
автоматике, несмотря на успешный локальный обход.

После этой проверки добавлен один повтор только при `ConnectTimeout`/`ReadTimeout`:
пауза 2 секунды, пределы одного запроса 15 секунд на соединение и 25 на чтение,
общий внешний лимит процесса сохраняется. Ошибки TLS, CAPTCHA и HTTP-отказы не
повторяются. Повторный тайм-аут оставляет прежний курсор и неполный статус.

[Итоговая облачная проверка 502c482](https://github.com/12bladick12/skb-competitor-analytics/actions/runs/38877544575)
подтвердила ограниченный эффект повтора: запрос названия ТЕКО после первого
`ConnectTimeout` получил карточку со второй попытки (18,8 секунды HTTP-этапа).
Для ИНН МЕГА-К, СЕНСОР, СОЧЕР и Сенсорен Электро обе попытки завершились
`ConnectTimeout` примерно за 32 секунды; обход этих организаций остановлен с
сохранением позиции. Браузерный поиск ВС без окна ответил, последующая проверка
с окном завершилась тайм-аутом навигации. Даже восстановленный публичный маршрут
ВС остаётся нестабильным из выбранного облака. Успешный статус диагностического
workflow означает завершение проверки, а не успешный полный сбор данных.

### Оставшиеся ограничения

После исправления интерфейсных ошибок КАД и Банк решений в Edge доходят до поиска,
но получают ошибку WebAssembly `unreachable` без выдачи. Обычный HTTP-запрос
`/Ras/Search` дополнительно вернул 451. Повторный Firefox с отдельным сохраняемым
профилем также не дал результатов: КАД остановлен внешним лимитом 75 секунд,
Банк решений — тайм-аут поискового ответа. В GitHub Actions проверен Chromium
с окном через уже установленный Xvfb, отдельным профилем и загрузкой всех ресурсов;
КАД/Банк решений также завершились ошибкой WebAssembly. Ни механизм ограничения,
ни возможность его устранения заменой библиотеки этим не доказаны.

У КС проверены адреса с `www` и без него: локально ошибка доверия к сертификату,
из Actions — тайм-аут. Проверка TLS не отключалась. Сравнение запроса ВС через
установленное хранилище Windows не показало улучшения; доверенные корневые
сертификаты не добавлялись. Ограничения ФССП, Федресурса и неполнота региональных
судов по-прежнему не сняты.

Дополнительно проверен ранее известный официальный портал `api-ip.fssp.gov.ru`:
GET главной страницы вернул HTTP 410 со страницей отказа. Доступность регистрации
и бесплатной выдачи API-ключа сейчас не подтверждена; старые инструкции не дают
оснований считать этот маршрут рабочим. Заявки и сообщения не отправлялись.

В проверенных бесплатных средах полный автоматический сбор всех заявленных
категорий пока недостижим. Исправления кода не дают права объявлять недоступный
реестр пустым. Следующий непроверенный вариант — официальный разрешённый доступ
или пробный API с сопоставлением контрольных дел; доступы ещё не получены.
Это предел текущего решения, а не доказательство невозможности любых будущих
способов. Публичный допуск остаётся закрыт, 14-дневная приёмка не начата.

## Что изменено в сборщике

- Навигация ждёт получения документа, затем конкретного элемента/ответа поиска.
  Зависший сторонний виджет больше не обязан удерживать весь этап навигации.
- Не загружаются только перечисленные необязательные счётчики и виджеты.
  Скрипты суда, формы, стили, проверки доступа и CAPTCHA не блокируются.
- Ошибка содержит этап, HTTP-статус и безопасный код сетевой ошибки. Тексты
  исключений с возможными параметрами доступа не попадают в журнал.
- ФНС использует проверенную публичную HTTP-форму. Ожидание результата ограничено;
  совпадение проверяется одновременно по ИНН и ОГРН, временные токены удаляются.
- ФССП использует action своей публичной формы. CAPTCHA отдельно регистрируется;
  последующие запросы компаний к заблокированному источнику в этом запуске прекращаются.
- Полнота судебного мониторинга остаётся неподтверждённой. Внутренний статус
  `partial` записи ФНС означает ограничение истории, даже если реквизиты совпали.

## Воспроизводимость

Уже имеющиеся зависимости: Playwright, requests, BeautifulSoup. Новые Python-библиотеки,
корневые сертификаты, прокси и платные сервисы не устанавливались. После явного
согласия пользователя установлен Firefox 150.0.2 для Playwright (build 1522).

```powershell
python scripts/diagnose_court_access.py --mode http --output data/access-http
python scripts/diagnose_court_access.py --mode browser --channel msedge --output data/access-browser
python scripts/probe_court_sources.py --sources fns --entity all --output data/fns-check --channel msedge
python scripts/probe_court_sources.py --sources kad ras mkad --output data/firefox-check --browser firefox
python -m unittest discover -s tests -p test_courts_access.py -v
```

Снимки HTML и полные ответы сохраняются только в игнорируемом `data/`; в публичные
артефакты Actions они не выгружаются. Workflow `Public court source access audit`
проверяет те же адаптеры в Ubuntu/Chromium без секретов рабочей базы, включая
отдельный проход ФНС по всем пяти компаниям. Доступность на локальном компьютере
не заменяет результат из среды запуска и 14-дневную проверку устойчивости.

Если требуются дополнительные библиотеки или браузеры, их установка предварительно
согласовывается с пользователем. Ключи платных API по-прежнему не получены.
