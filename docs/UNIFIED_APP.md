# Одно приложение с двумя вкладками

## Что опубликовано

- Репозиторий: `12bladick12/skb-competitor-analytics`, ветка `main`.
- Файл запуска: `streamlit_app.py`, Python 3.13.
- Адрес: https://skb-competitor-analytics.streamlit.app/ . Новое приложение создавать не нужно.
- Вкладки: «Новости конкурентов» и «Цены конкурентов».

Новости сохраняют Google-вход, роли сотрудников, Neon и Google Drive. Вкладка цен публичная:
посетители видят общие товары и сравнения, могут запускать и останавливать сбор. Ее история
остаётся в существующей схеме `price_monitor` базы Supabase. Таблицы заново заполнять не нужно.

## Однократные действия владельца в Streamlit

1. Откройте прежнее приложение цен → **Manage app → Settings → Secrets**.
2. Скопируйте только раздел `[database]` со всеми его строками. Не публикуйте значения в GitHub или чате.
3. Откройте основное приложение `skb-competitor-analytics` → **Settings → Secrets**.
4. Добавьте `[database]` в конец существующих Secrets. Сохраните все прежние разделы
   `[cloud]`, `[auth]`, `[access]`, `[drive]`. Если `[database]` уже есть, обновите его, не дублируйте заголовок.
5. Сохраните настройки и выполните **Reboot app** основного приложения. Репозиторий,
   ветка `main`, файл запуска и URL остаются прежними; адрес Google OAuth менять не нужно.
6. Откройте вкладку «Цены конкурентов». Ранее сохранённые запуски и товары должны быть доступны.
7. Когда история и база товаров доступны по основному адресу, удалите прежнее приложение цен
   из рабочего пространства **Streamlit**. Его активный процесс удерживает очередь общего сборщика.
   Базу Supabase, GitHub-ветку и внешний агент Sensoren удалять не нужно.
8. Основное приложение заберёт свободную очередь автоматически; на освобождение старой блокировки
   может потребоваться до двух минут. Не запускайте новую большую очередь, пока основной сборщик не подключился.

Ветка `price-monitor` остаётся архивом отдельного приложения. До завершения переноса она
и прежний адрес продолжают работать. Новые изменения единого приложения публикуются в `main`.

В этой рабочей папке подготовлен локальный файл `.streamlit/secrets.price-database.toml` с тем же
подключением. Он исключён из Git и может использоваться вместо копирования из прежнего приложения.
Доступа к панели владельца Community Cloud из среды разработки нет, поэтому добавление Secrets
и перезапуск выполняет владелец.

## Ссылки и навигация

| Раздел | Ссылка |
| --- | --- |
| Новости | `/?workspace=news` |
| Прежняя ссылка обзора | `/?section=Обзор&period=2026-09` |
| Сбор цен | `/?workspace=prices&price_section=collect` |
| База товаров | `/?workspace=prices&price_section=products` |
| Сравнение цен | `/?workspace=prices&price_section=compare` |
| История модели | `/?workspace=prices&price_section=history&model=<id>` |

Выбор вкладки не очищает период и фильтры новостей. Несохранённые правки записки требуют
сохранения или явного отказа перед переходом к ценам. Задания сбора и результаты хранятся в базах;
переключение вкладки не отменяет сбор. После перезапуска приложения откройте вкладку цен для
запуска её фонового обработчика. При засыпании Community Cloud обработка продолжится после пробуждения.

## Код и данные

- `streamlit_app.py` — общий интерфейс, вкладки и новости.
- `cloud/`, `src/` — прежние модули новостей и обработчик новостей.
- `price_monitor/ui.py` — интерфейс цен, остальные `price_monitor/` — хранение и сбор.
- `examples/comparison_template.xlsx` — шаблон явного сопоставления и наших цен.
- `docs/prices/` — аудит источников и инструкции сборщика цен.

Пароли, рабочие базы, архивы документов и снимки сайтов не входят в репозиторий.
Автоматический подбор аналогов не включён: соответствия и наши цены задаются явно.
